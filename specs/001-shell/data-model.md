# Phase 1 Data Model: The Shell

No entities. This feature has no content collection, no schema, and no data
of any kind — it is layout, navigation, and typography built from static
markup. `spec.md`'s own template omits the Key Entities section for the same
reason.

The real content model — one file per piece, with `title`, `description`,
`image`, `alt`, `captionBackground`, `captionText`, `order` — is already
specified in root `PLAN.md` §3 and arrives with Milestone 2
(`SPEC.md` §2). Nothing here should anticipate or duplicate it.
